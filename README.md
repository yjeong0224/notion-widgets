# Notion Widgets v2

변경사항:
- 목표 입력창은 기본 숨김. `+ 추가하기`를 눌렀을 때만 표시.
- 주간/월간/올해 목표는 `예정 / 진행중 / 완료` 상태 지원.
- 진행률은 `완료` 항목만 반영.
- 주간 표시를 `YYYY.MM.DD~YYYY.MM.DD` 형식으로 변경.
- 비상금 버튼을 작게 조정.
- `되돌리기`, `리셋`을 테두리 없는 텍스트 버튼으로 변경.

중요: v2는 저장 키를 `nw.v2`로 사용합니다. 이전 v1 데이터와 별개로 저장됩니다.

- 종합 진행률 위젯을 세로형 리스트 레이아웃으로 변경.
- 진행률 바와 저축 바 포인트 컬러를 `#eca4b0`으로 변경.

- 주간/월간/연간 상태 선택 드롭다운 제거.
- 네모 상태 버튼을 클릭할 때 `예정 → 진행중 → 완료 → 예정` 순으로 순환.
- 상태 버튼은 핑크색이 아닌 검정/회색 계열 사용.
- 진행률 바/저축 바의 핑크 포인트 색상은 그대로 유지.

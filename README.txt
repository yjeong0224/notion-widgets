Notion Widgets v17 — 기간별 목표 분리 수정

설치
압축을 풀고 모든 파일을 기존 GitHub 저장소의 같은 폴더에 덮어쓰세요.
progress.html / savings.html은 업로드 원본의 (1)을 뺀 배포용 이름입니다.
기존 웹 주소는 유지됩니다. 반영 후 위젯을 새로고침하세요.

수정 사항
- 새 기간에 다른 기간/구버전 목표를 자동 복사하던 동작 제거.
- 오늘 목표: 매일 새 목록. 주간 목표: 월요일마다 새 목록.
- 장기 목표: 월별/연도별 새 목록.
- 화면을 열어 둔 상태에서도 기간 변경 감지. 잠자기 후 복귀 시에도 확인.
- 과거 기간을 직접 열어 보고 있으면 해당 기간 유지.
- 기존 기간별 기록과 완료 상태 보존.
- 목표 진행률에서 진행중 표시 제거.

이미 잘못 복사되어 저장된 목표는 자동 삭제하지 않습니다.
해당 날짜에서 중복 항목만 한 번 삭제하세요. 전날 기록에는 영향이 없습니다.
날짜 기준은 사용 기기의 현지 시간이며 주의 시작은 월요일입니다.
기록은 기존과 동일하게 해당 브라우저의 localStorage에 저장됩니다.

 v17 추가 수정
- 오늘/이번주/장기목표 우측 상단 진행률 제거.
- 이번주/장기목표: 빈칸 → 점(진행중) → 체크(완료) → 빈칸 순환.
- 오늘 목표는 기존처럼 한 번 클릭으로 완료.
- 진행률은 완료 항목만 반영. 진행중 숫자는 표시하지 않음.
- 목표 진행률/비상금 막대 채움색: 첨부 이미지의 대표색 #eeb6cb.
- 비상금 리셋: 팝업 없이 즉시 0원, 목표 유지 및 되돌리기 지원.

공부 위젯 대분류 업데이트
- 영어와 중국어는 별도 HTML로 사용합니다.
- 회색 디자인이며 추가 입력에서 회독과 단위를 제외했습니다.
- 대분류·항목 / 현재·전체 / 메모 / 자료 링크 순서로 입력합니다.
- 새 항목은 진행중으로 시작하고 항목 옆 버튼으로 진행중·완료를 전환합니다.
- 저장은 폼 제출 없이 버튼에서 직접 처리하고 성공 또는 오류를 표시합니다.
- 기존 기록은 미분류에서 수정할 수 있습니다.
- 기록은 브라우저 로컬 저장소에 보관되며 기기 간 자동 동기화되지 않습니다.
- 같은 호스팅 주소와 브라우저에서 기존 파일을 교체해 주세요.

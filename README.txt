# Notion Widgets v8 — 날짜 이동 기능 추가

업로드할 파일:
- `longterm.html` : 장기 목표
- `today.html` : 오늘의 할 일
- `week.html` : 이번주 할 일
- `shared.css`
- `shared.js`

## 추가된 기능
### 장기 목표
- 이번 달 탭: 제목 아래 `2026년 10월`처럼 실제 월 표시
- 올해 탭: `2026년`처럼 실제 연도 표시
- 표시된 기간을 누르면 날짜 선택기가 열림
  - 이번 달: 선택한 날짜의 월로 이동
  - 올해: 선택한 날짜의 연도로 이동
- 월/연도별 목표를 각각 따로 저장하므로 지난 목표를 다시 볼 수 있음

### 오늘의 할 일
- 좌우 화살표로 하루씩 이동
- 날짜를 누르면 달력에서 원하는 날짜로 바로 이동
- 날짜별로 할 일이 별도 저장됨

### 이번주 할 일
- 좌우 화살표로 한 주씩 이동
- 주간 날짜를 누르면 달력에서 원하는 날짜를 선택 → 그 날짜가 속한 주로 이동
- 주별로 할 일이 별도 저장됨

## GitHub에 올리는 방법
기존 저장소에서 같은 이름의 파일들을 이 파일들로 덮어쓰면 됩니다.
GitHub Pages가 켜져 있으면 기존 주소는 그대로 유지됩니다.

## 기존 데이터
첫 실행 시 브라우저 localStorage에서 `today`, `week`, `longterm`, `goals` 등
흔한 기존 키를 찾아 현재 기간으로 복사하도록 호환 코드를 넣었습니다.
기존 키는 삭제하지 않습니다.


## v9 장기목표 UI 수정
- 이번 달: 일자 달력 없이 월만 선택
- 올해: 월 선택 없이 연도만 선택
- 목표 추가 UI를 하단의 작은 `＋ 추가하기` 링크로 변경
- `＋ 추가하기` 클릭 시 작은 입력칸만 펼쳐짐


## v10 최종 컴팩트 UI

- 이번주 할 일: 입력칸 기본 숨김, `＋ 추가하기`만 표시
- 추가하기 클릭 시 작은 입력칸만 펼쳐짐
- 장기목표와 추가 UI 스타일 통일
